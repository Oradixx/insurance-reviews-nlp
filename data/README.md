# Data

The dataset is **not included** in this repository. It was provided by the course and contains
real customer reviews, with the authors' usernames.

## Expected input: `data/raw/`

35 Excel files named `avis_<n>_traduit.xlsx` (about 24,000 reviews after removing empty and
duplicate reviews). Columns used:

| Column | Content |
|---|---|
| `note` | star rating, 1 to 5 |
| `avis` | review text (French) |
| `assureur` | insurance company |

The files also contain the product (`produit`), the dataset split (`type`), dates, the author and a
first translation (`avis_en`), which are not used.

## Generated by the notebook: `data/processed/`

| File | Content |
|---|---|
| `reviews_clean.csv` | the reviews with `avis_cor` (cleaned + spell-checked French) and `avis_cor_en` (English translation) |
| `review_embeddings.pkl` | MiniLM embedding of every `avis_cor_en` (NumPy array, one row per review, same order as the CSV) |
| `vectors.tsv`, `metadata.tsv` | 1,000-review sample for the [TensorFlow Embedding Projector](https://projector.tensorflow.org) |

The Streamlit apps read `reviews_clean.csv` and `review_embeddings.pkl`.
